# 墨径后续路线图

本次交付仅包含 MVP。以下能力没有作为可用入口出现在应用中，也不计入当前验收。

| 后续方向 | 进入实施前需验证的事项 | 当前扩展基础 |
|---|---|---|
| 实体触控笔与大型资料优化 | 延迟、压感、防误触、低内存和百页/千卡性能，局部保存及资产回收 | PDF独立坐标、墨迹points/pressure、FileStore、版本迁移 |
| EPUB | 排版重流后的稳定段落定位、中文排版 | Source增加锚点类型并迁移；阅读器与知识卡片独立 |
| 网页与视频 | 本地快照、资源归档、段落或时间戳定位 | 资产索引与来源引用可增加媒体类型 |
| OCR | 对扫描图像生成可搜索文字层，准确保留原文坐标并标识机器识别 | 批注与来源几何独立于文字层 |
| AI 摘要与问答 | 用户授权、资料隐私、成本、引证准确性及离线功能边界 | 卡片生成/编辑入口可接独立服务；当前无AI依赖 |
| 实时云同步 | 稳定实体身份、冲突合并、删除标记、增量协议、加密和恢复 | UUID、内容哈希、交换包版本与完整性校验；当前仅离线副本迁移 |
| 多人协作 | 权限、版本并发、归属与审计，脑图关系冲突 | 当前本地单写者逻辑；未来单独设计协作协议 |
| 插件市场 | API边界、进程隔离、数据权限、包验证与兼容性 | 当前依赖接口与数据迁移，不提前开放执行权限 |
| 付费系统 | 商店政策、签名、账户与恢复购买 | 当前无需账户、无付费或占位购买入口 |
| MarginNote 私有格式导入 | 可用规范、可取得的数据、合法使用条件及完整映射 | 当前不读取私有格式；以自有版本化交换格式迁移 |

下一阶段优先处理真实设备反馈、低内存性能、可回收资源与安装更新体验，再评估新的资料类型和服务能力。历史数据升级必须有迁移及备份恢复测试。
