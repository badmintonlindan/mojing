# 墨径简明使用说明

墨径把原文、卡片、脑图与复习保存在当前设备，无需注册。Android 0.1.1 的修复与实际设备验证见 [发布记录](RELEASE-0.1.1.md)；Windows 交付仍为 0.1.0，其 MVP 历史验收见 [测试记录](TEST-REPORT.md)。

## 安装与进入

Android 安装交付的 APK；调试 APK 需要允许该文件来源安装应用。Windows 解压完整便携目录后运行 `墨径.exe`，不要单独移动 EXE。具体版本、文件位置与运行情况见交付测试记录。

Android 从 0.1.0 更新至 `墨径-0.1.1-Android.apk` 时直接覆盖安装，保留本机资料；不要先卸载旧版。更新前也可导出完整学习集另行备份。

宽屏将 PDF 与知识面板分栏显示，可拖动中间分隔条调整比例。Android 0.1.1 的宽屏标题栏新增“资料栏”按钮：点击收起左侧资料栏，阅读区随之变宽；再次点击即可展开。窄屏左上菜单打开抽屉，点击关闭按钮、侧栏外的遮罩或选择文档可将其收起。宽屏默认展开，窄屏默认关闭；此开关不随学习集交换包迁移。尚未更新的 Windows 0.1.0 便携版不含这个新开关。

手机使用底部“阅读 / 卡片 / 脑图 / 复习”切换。平板可旋转屏幕，界面按可用宽度改变布局。

手机横屏仍使用单栏切换，但常驻工具区占比较大，连续阅读建议用竖屏。实体触控笔的延迟与防误触体验仍需真机复测；本次已在真实Android WebView验证手指和模拟pen事件的手写、压力记录及仅笔模式。

## 1. 导入资料与建立学习集

选择“导入 PDF”，可同时选多份文件。首次导入会创建“我的学习集”，也可以先创建命名学习集。原文件会复制进应用资料库，之后移动原始文件不会影响阅读。

“资料库”提供名称搜索、重命名和删除，也可把已有 PDF 关联至当前学习集。同一份资料可用于多个学习集，卡片与批注属于各自的学习集。删除学习集时保留资料库 PDF；删除资料库 PDF 时会移除相关批注，已有卡片仍保留正文和图片，来源显示为已移除。

## 2. 阅读、批注与摘录

阅读区底部可以前后翻页、输入页码后按 Enter 跳转、缩放以及每次旋转 90°。点击缩放百分比恢复适宽。阅读页码、缩放和旋转会自动保存。

Android 0.1.1 中，将两指放在原文上，分开放大、合拢缩小。手势期间显示缩放预览，松指后保存并清晰重绘；放大后可用单指平移查看。双指可在浏览、选字、区域摘录、手写笔和橡皮模式接管缩放，接管时取消尚未完成的临时操作。双指缩放已在 Android 平板模拟器的真实 WebView 及浏览器可信触摸事件中验证，华为实体平板和实体触控笔仍需实际设备复测。

| 工具 | 操作 |
| --- | --- |
| 浏览 | 拖动阅读画面；Android 0.1.1 支持上述双指缩放与松指重绘 |
| 选字 | 拖选文字后，点击“复制”“高亮”或“摘录卡片”；Android 也可使用系统文字选择操作 |
| 查找 | 输入 PDF 原文关键词后“查找”，从页级结果跳转；只搜索文字层，不对扫描页做 OCR |
| 区域摘录 | 在原文拖出一个矩形，生成截图卡片；适用于扫描页、图表和公式 |
| 手写笔 | 在页面书写，选择笔颜色；“仅触控笔”开启时仅笔输入留下墨迹，手指用于移动 |
| 橡皮 | 点击或划过批注移除对应整条笔迹/高亮，并非像素橡皮 |
| 撤销 | 撤销本次打开文档期间的批注增删；重新打开文档后不保留撤销栈 |

截图卡片保留原文图像及位置，应用批注单独保存，不写入原 PDF。缩放、旋转和调整窗口不会改变保存的 PDF 来源坐标。

## 3. 整理知识卡片

摘录文字或截图后会打开卡片编辑器。也可选择“新建卡片”记录自己的解释。填写标题、正文、标签，选择颜色；可另行附加 PNG、JPEG 或 WebP 图片。标签用中文或英文逗号分隔，保存后自动持久化。

卡片列表可搜索标题、正文和标签，也可按标签筛选。点击卡片标题或编辑图标修改内容；修改会同步到引用该卡片的脑图和复习答案。删除卡片会同时删除对应脑图引用、复习安排及其记录，脑图子节点提升至仍存在的上级。

原文摘录卡片底部显示文档名称和页码。点击来源打开对应 PDF 页面，并在保存区域显示定位框。手工卡片没有自动来源；原文已被删除的卡片不再提供跳转。

## 4. 连成知识脑图

卡片上的“加入脑图”将它作为根节点加入当前学习集脑图。脑图中也可点击“根节点”，从已有卡片选择引用。选择节点后，可添加子节点、同级节点，或点击“移动”选择新的父节点；拖到另一个节点上也可改变父级。自己的子树不会作为可选父级。

向上/向下按钮调整同级顺序。节点上的箭头折叠或展开子节点；“自动布局”适配当前树。拖动空白处平移，使用画布右下角按钮缩放/适应，鼠标可用 Ctrl + 滚轮缩放。编辑节点会编辑其共用卡片；来源图标或底部选中节点的“原文”按钮可以返回来源。

“移除脑图节点”只移除引用，保留知识卡片，并提升子节点。脑图层级、顺序与折叠状态会保存；画布视角暂不在重启后恢复。

## 5. 用卡片复习

在卡片选择“加入复习”，将标题改写成一个可以主动回忆的问题；答案使用卡片正文与图片。之后编辑卡片会同步更新答案。在复习的“复习安排”页面可修改问题，也能一次添加当前学习集全部卡片。

“开始复习”默认显示到期内容。先尝试回忆，再“显示答案”，选择“再学一次 / 有些困难 / 已掌握 / 很轻松”。系统记录掌握反馈并安排下一次时间；“再学一次”为 10 分钟后，其余按天逐步拉长间隔。“记录”显示反馈时间和下次时间，重启后仍保留。没有到期内容时可选择“练习全部卡片”。首版不发送到期通知。

## 6. 备份、迁移与导出

侧栏“备份当前学习集”导出 `.mjstudy` 文件，包含关联 PDF、图片、卡片、批注、脑图、阅读状态、复习安排及记录。把文件复制到另一设备，在墨径选择“导入学习集”。导入会先校验格式版本、文件大小、SHA-256 及关系，再创建新学习集副本；即使同名或重复导入也不会覆盖原数据。

Android 会打开系统文件保存器，准备大扫描资料时请等待。某些系统会给文件名附加 `.zip`，例如 `学习集.mjstudy.zip`；可以直接在墨径导入，无须解压。取消系统保存不会删除学习数据。

顶栏“导出笔记”生成 ZIP，解压可见 `笔记.md` 与图片/原文附件。保留相对目录结构即可使用其中的离线图片和 PDF 页码链接；Markdown 记录来源页码与区域坐标。

看到顶栏“已保存到本机”后再关闭应用。若显示保存失败，请保持窗口，使用“重试保存”或导出备份。自动保存不是异地备份：卸载 Android 应用、清空应用数据或删除 Windows 数据目录会移除本机资料。建议定期将完整学习集复制到另一位置。

## Windows 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl + O | 导入 PDF |
| Ctrl + K | 新建卡片 |
| Ctrl + S | 保存 |
| Ctrl + E | 备份当前学习集 |
| Ctrl + 滚轮（阅读区或脑图） | 缩放当前原文或脑图 |

文件大小限制、未验证的设备能力和暂不支持的格式见 [已知问题](KNOWN-ISSUES.md)。
