# 已知问题与验证边界

此文件描述当前代码的限制；目标平台的最新构建/运行结果和具体环境障碍见 [TEST-REPORT.md](TEST-REPORT.md)。已实现、已构建、已运行验收分别记录。

## 设备与验证范围

- 已完成 Chrome 三类布局、打包 Windows 原生完整交互，以及安装 APK 的 Android 手机/平板模拟器离线操作、横竖屏、真实系统文件保存和双向迁移。实体 Android 手机/平板尚无硬件测试证据；模拟器测试不代表所有厂商设备兼容。
- 未完成实体 Android 触控笔的延迟、压感、防误触和多指组合测试。“仅触控笔”依据 Pointer Events 的 `pointerType` 过滤；当前墨迹使用固定线宽，保存的压力值不用于动态笔宽。
- 仅声明 Android API 24 以上；PDF.js 运行仍依赖设备提供足够新的 System WebView。尚未建立最低 WebView 版本的兼容性矩阵。
- 本次原生验证为 Android 15 / API 35、System WebView 124.0.6367.219。PDF.js [上游当前 legacy 支持矩阵](https://github.com/mozilla/pdf.js/wiki/Frequently-Asked-Questions#which-browsersenvironments-are-supported)从 Chrome 125 起列示；本项目在124额外实测了MVP流程，其他旧版WebView未穷尽，建议保持系统WebView更新。
- 手机横屏约818×388 CSS像素时保持单栏、所有核心操作可用，但常驻工具区占较多高度，PDF可视区约80 CSS像素；连续阅读建议使用竖屏。横屏全屏阅读/紧凑工具栏列入下一阶段，不把无横向溢出等同于阅读体验充分优化。
- PDF 样例包含可选文字文档、官方 PDF.js 外部论文、Smithsonian真实档案扫描及纯位图模拟扫描。档案部分页带原有低质量 OCR，本应用没有运行 OCR；不同编码、加密、损坏或超大PDF仍未穷尽。

## 功能与数据限制

- 支持 PDF。加密且需要密码的 PDF 暂无密码输入流程。EPUB、网页、视频、OCR、AI、云同步、协作、插件、付费与 MarginNote 私有格式不在本次范围。
- 批注保存于墨径学习数据中，不写回原始 PDF。区域截图摘录原文渲染图像，不把应用高亮或笔迹烘焙到图片中。
- 橡皮按整条笔迹/高亮删除，未提供像素擦除。撤销栈只在当前文档打开期间保留，无跨重启撤销或重做。
- 脑图自动树布局，不支持任意固定自由坐标。层级、顺序与折叠保存；画布平移/缩放视角和分栏比例暂不跨重启保存。
- 复习采用确定的间隔调度，问题独立保存、答案引用卡片。不发送系统通知，不宣称使用完整 SM-2/FSRS 等算法。
- 本地状态使用版本化 JSON 双槽快照，不是 SQLite。每次保存会复制并校验完整状态，大数据集性能需要后续量测。PDF、截图、ZIP 和原生桥接数据会在内存中处理，尚未完成超大文件和低内存 Android 压力测试。
- 单个 PDF 导入限制 150 MiB。完整交换包限制 256 MiB、解压 512 MiB、5000 个条目、单个 JSON 16 MiB；多份大 PDF 可能达到交换包上限。失败会显示原因，不静默截断。
- 删除数据后，未引用的资产文件暂不立即物理回收，以保留上一槽恢复所需资源。大量反复导入/删除可能增加磁盘占用；首版没有自动垃圾回收界面。
- `.mjstudy` 是带 SHA-256 完整性清单的普通 ZIP，没有密码加密或身份签名。SHA-256 校验用于发现损坏，不用于证明文件来自可信发布者。重复导入始终创建副本，不提供覆盖合并。
- 无账户同步。同一设备的浏览器开发版、Android 安装版和 Windows 安装版各有独立数据目录；交换文件才是迁移方式。清空浏览器站点数据、卸载 Android 或删除应用数据目录会移除本机资料。
- 当前交付路线是 Android 调试 APK 与 Windows x64 便携程序，没有商店签名、Windows 安装向导、自动升级或跨进程并发编辑协调。Windows 对同一数据目录使用单实例锁，再次启动会聚焦已有窗口。
