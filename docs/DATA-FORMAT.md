# 墨径数据与交换格式 v1

所有端共用 `src/core/model.ts`、`repository.ts` 和 `exchange.ts`。应用无需账户或网络。

## 标识与定位

学习集、文档、卡片、批注、脑图节点、复习计划和复习记录使用独立稳定 ID。卡片内容仅存储一份，脑图通过 `cardId` 引用。脑图父节点必须属于同一学习集，禁止循环。来源包括文档 ID、从 1 开始的页码、一个或多个矩形，以及可选原文摘录。

来源矩形和手写点保存为 PDF 未旋转用户空间的坐标，使用 PDF.js 对应页 `PageViewport.transform` 统一转换。坐标不随屏幕像素、设备 DPI、窗口大小或用户缩放保存；PDF 裁切区域及文档内建旋转由 PDF.js viewport 处理。矩形为 `[x1,y1,x2,y2]`，须满足 `x1<=x2`、`y1<=y2`。手写线宽也使用 PDF 用户单位。

## 本地保存

应用的文件适配器提供相同的二进制 `read/write/remove` 合同。PDF 和图片资源存入应用私有目录，路径为 `assets/<SHA-256>.<扩展名>`，内容寻址并去重。资源先写入，再登记学习数据。相同内容并发导入时按哈希共享进行中的操作，底层文件只写一次，元数据只登记一次；失败后可重试。每次读取资源检查大小和 SHA-256。

逻辑数据库采用 JSON 快照，`schemaVersion=1`，不是 SQLite。每次保存包含递增 `revision`、完整 state 及对 state JSON 字节计算的 SHA-256。`snapshot-a.json` 与 `snapshot-b.json` 交替保存；只有写入并读回核验成功才切换当前槽。连续失败始终重试非成功槽，保留最近成功快照。保存按调用顺序排队，并在调用时复制 state，避免异步写入时读到稍后 UI 修改的对象。

启动检查两槽并选择最高有效修订。单槽损坏时恢复有效槽并显示警告。两槽都损坏时明确报错，保留文件，不以空库覆盖。如果任一完整快照具有更高 schemaVersion，拒绝降级加载，防止旧应用覆盖新数据。

迁移函数目前明确支持内部 v0 到 v1（补充复习记录、脑图、批注数组及文档阅读状态），未来版本必须继续增加有测试的显式迁移。不存在的版本不作猜测恢复。

删除文档会解除学习集关系并删除该文档批注；已有卡片保留正文/截图，将来源名称及页码保存到 `orphanedSource`，不再提供无效来源跳转。删除卡片会删除其脑图引用和复习数据，脑图子节点提升至被删引用的父节点。资源文件不会在普通删除时即时物理回收，便于上一槽恢复；后续版本可增加覆盖所有有效快照的资源回收。

## 完整学习集交换包

交换包是 ZIP，应用扩展名为 `.mjstudy`。结构如下：

```text
manifest.json
study.json
assets/<SHA-256>.pdf
assets/<SHA-256>.png
```

`manifest.json` 包含 `format="mojing.studyset"`、`version=1`、`schemaVersion=1`、`hashAlgorithm="SHA-256"`、`studySetId`、导出时间，以及每个其他文件的路径、字节数、SHA-256。`study.json` 是只包含一个学习集及全部关联记录的 State。包含原 PDF、卡片图片、批注、脑图、阅读状态、复习计划和历史。

导入先校验 ZIP 条目路径、数量、解压大小，再核对每个文件的大小/哈希及全部数据关系。拒绝重复/未知路径、路径穿越、缺少或多余资源、未来版本、无效页码、悬空引用和脑图循环。校验通过后写入资源，并一次保存合并状态。导入始终创建新的学习集副本，重新分配所有逻辑实体 ID 并完整映射关系；已有数据不会被静默覆盖。相同 SHA-256 的资源可以复用。

首版交换包上限：压缩文件 256 MiB、解压总大小 512 MiB、5000 个文件、每个 JSON 元数据文件 16 MiB。导出与导入使用相同限制。ZIP 处理在内存中完成，大资料集仍需要后续流式处理。

Markdown 提供独立文本导出，以及包含 `笔记.md` 和原文/图片资源的 ZIP 导出。后者的相对资源链接可以离线使用；来源信息保留页码、PDF 区域及原文摘录。

## 验证范围

`tests/core.test.ts` 验证坐标往返、保存中断及连续失败、重启恢复、未来版本拒绝、脑图循环/移动/删除、复习安排、20 张卡片三级脑图的完整包恢复、重复导入冲突、篡改与路径穿越拒绝、Markdown 资源完整性。单元测试中的 PDF/PNG 字节是签名夹具，仅验证数据可靠性；真实文件渲染、批注交互及跨平台运行需另行验收。
