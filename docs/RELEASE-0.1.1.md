# 墨径 0.1.1 · 平板阅读修复

此版本针对平板用户反馈的“课件放大不正常”和“左侧资料栏无法收起”。不变更学习数据 schema 或交换包版本。

## 改动

- 宽屏标题栏新增“资料栏”按钮，可收起左侧资料栏并释放阅读宽度，再点重新展开。窄屏继续使用左上菜单、关闭按钮和遮罩。
- 双指手势期间只缩放原文、文字层和批注的显示预览；松手后提交缩放、保存并清晰重绘一次，避免每个手指移动都重建 PDF 位图。
- 保持两指中心对应的 PDF 位置；加减按钮、Ctrl+滚轮也使用缩放中心补偿。
- 选字、手写、区域摘录和橡皮模式均可由第二指接管缩放。接管时取消临时笔迹/截图，并恢复第一指刚擦除的笔迹，避免误操作。
- 来源跳转后立即缩放不再被尚未结束的来源定位再次滚回。
- 分栏条获得键盘焦点时，左右箭头只调整分栏比例，不再同时触发 PDF 翻页。
- 高 DPI、高倍缩放的最终位图限制为最多16Mi像素（RGBA约64MiB）、单边8192像素，页面CSS尺寸与PDF坐标保持不变；不是对原PDF降质保存。

## 安装

使用 `release/墨径-0.1.1-Android.apk` 直接覆盖安装旧版。包名仍为 `cn.mojing.study`，versionCode从1增至2，使用相同调试证书。不要为了更新而卸载旧版，因为卸载会删除本机资料。

对应源码与本次证据包路径为 `release/墨径-0.1.1-源代码.zip`。Windows 交付仍为 `release/墨径-0.1.0-Windows-x64.zip`；本次没有发布新的 Windows 二进制。

打开课件后可在任一阅读工具模式用双指放大/缩小，松手等待清晰重绘；底部“＋/－”与百分比适宽仍可使用。宽屏左上标题栏的“资料栏”按钮负责收起/展开资料。
