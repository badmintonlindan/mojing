# 0.1.1 阅读缩放回归

最终入口 `index-BxRt8DSg.js`，4 项测试全部通过（43.5 秒）。脚本为 `tests/reader-zoom.spec.ts`，每项 JSON/截图位于 `final/`，汇总为 `browser-final.json`。

- Chrome 可信 CDP 多指触摸：两种松指顺序；100 次移动期间 canvas 尺寸写入 0 次，松手后 width/height 各写一次。固定手势中心的最终漂移约 0.167 CSS 像素，预览漂移约 0.00004 像素。
- 选字模式可双指缩放；touchCancel 后能再次双指缩放和单指平移。两次真实 pointercancel 均被观测到。
- 按钮放大/缩小、4 倍、90 度旋转、分栏键盘调整与窗口扩大后渲染非白。最终画布 4659×3600=16,772,400 像素，低于 16 Mi 像素预算，全画布不透明；530,396 个深色原文像素。
- 批注保存的 PDF 点、宽度等全部字段保持原值，旋转后的 SVG 点另按 PDF 坐标独立核对。分栏键盘调整不会再误翻页。

`candidate/` 保留首轮失败证据：分栏 ArrowRight 冒泡误翻到第 3 页是真实问题，随后由主实现修复；首轮按钮中心探针错误使用 46%/47% 位置，最终已修正为按钮实际锚定的 50% 视口中心。没有把测试探针失配当成产品缩放失败。

本组证据来自安装的 Chrome 浏览器和平板视口/DPR2，以 CDP 注入可信触摸。没有连接华为实体平板，不能宣称已验证用户那台设备。按主代理要求优先最终回归，没有额外运行 0.1.0 缩放基线。原 MVP 验收资料未改动。
